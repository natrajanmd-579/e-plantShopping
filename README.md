# e-plantShopping

## 🌿 Project Overview

e-plantShopping is a web-based application designed to provide users with an easy and convenient way to browse, select, and purchase plants online. The platform offers a wide variety of plants along with detailed information, helping users make informed decisions.

## 🚀 Features

* Browse different categories of plants
* View plant details and pricing
* Add plants to cart
* User-friendly interface
